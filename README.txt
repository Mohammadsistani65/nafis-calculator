راهنمای انتشار ماشین‌حساب نفیس (PWA)

۱) در GitHub یک مخزن (Repository) جدید بسازید؛ مثلاً nafis-calculator
   (اسم مخزن مهم نیست؛ مخزن‌های دفتر فروش و پروژه‌های اصلی را تغییر ندهید).
۲) همه‌ی فایل‌های این پوشه را (index.html، manifest.webmanifest، sw.js و پوشه‌ی icons) آپلود کنید.
   فایل‌ها باید مستقیماً در ریشه‌ی مخزن باشند، نه داخل یک پوشه‌ی اضافه.
۳) Settings > Pages > Source را روی Deploy from a branch و شاخه‌ی main و پوشه‌ی root بگذارید.
۴) بعد از چند دقیقه لینک شما این شکلی است:
   https://USERNAME.github.io/nafis-calculator/

نصب روی گوشی:
- اندروید (Chrome): لینک را باز کنید؛ دکمه‌ی «نصب روی گوشی» در بالای صفحه ظاهر می‌شود، یا از منوی مرورگر Install app را بزنید.
- آیفون (Safari): دکمه‌ی اشتراک‌گذاری > Add to Home Screen.

بعد از نصب، برنامه با آیکن خودش و بدون نوار مرورگر باز می‌شود و بدون اینترنت هم کار می‌کند.

اگر بعداً فایل‌ها را عوض کردید، در sw.js عدد نسخه‌ی nafis-calc-v1 را به v2 تغییر دهید تا گوشی‌ها نسخه‌ی جدید را بگیرند.
